# MastiPredict Validation Plan

1. Define reliable reference outcomes.
2. Build animal-wise longitudinal records.
3. Use animal-level and/or time-based data splitting.
4. Establish baseline models.
5. Compare single-modality and multimodal configurations.
6. Test missing/degraded modality robustness.
7. Compare 7-day and 14-day target horizons.
8. Report precision, recall, specificity, F1, ROC-AUC, PR-AUC, and calibration.
9. Document limitations and field-validation requirements.

The 7-day and 14-day horizons are research targets and must not be presented as validated performance until supported by appropriate data.
